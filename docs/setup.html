Set up

Set up Cade in minutes. An AI agent guides you.

You get one Cloudflare Worker, one Slack app and, if you like, a Google Sheet. There's no server to run. An AI coding agent does the setup with you: it runs each command, checks it worked, and stops whenever it needs you to click something.

  1. 1

    Copy Cade to your own repo

    On Cade's GitHub page, click Fork, or Use this template for a copy without its history. Your copy is what you deploy, and where you pull updates into later. Then clone it:

    git clone https://github.com/<you>/<your copy>.git cade
cd cade
npm install
  2. 2

    Start the guided setup

    Install Claude Code, then in your cade folder run:

    npm run setup

    It starts Claude Code with the setup prompt already loaded. Anything after -- goes to Claude Code, such as npm run setup -- --model opus.

    Any coding agent that can run terminal commands works, such as Cursor, GitHub Copilot, Codex or Gemini CLI. Open it in your cade folder and paste this prompt (it's also in scripts/setup-prompt.md):

    Set up Cade for me by following GETTING_STARTED.md, one step at a time.
Before each step, tell me what it does and what you'll run. Run the
commands yourself, check the result against the step's Expect, and
fix what you can using its If it fails. Stop and tell me exactly what
to do whenever a step needs a person: browser logins, approvals, Slack
and Google settings, and creating or inviting channels. Ask me for every
value you need (names, channel IDs, the time zone) instead of guessing.
Never ask me for a token or secret, and never put one in a file, a
commit or a command: the commands that need one (`slack:create`,
`slack:update`, `wrangler secret put`, `npm run dev`) ask for it
themselves, hidden. For those, give me the exact command to run in a
separate terminal window, in this folder (not with !, which can't take
hidden input), wait for me, then check the result. Ask before deleting
anything, and before running a step a second time.
  3. 3

    Follow along

    Before each step the agent says what it does and what it'll run, then runs it and checks the result. It stops and tells you exactly what to do when a step needs a person:

    • Logging in to Cloudflare, and to Google for the Sheet, in your browser
    • Making a Slack app configuration token, and installing the app
    • Creating the channels and inviting Cade to them
    • Telling it the channel IDs and your team's time zone
  4. 4

    Try it

    Post a message in your client channel: Cade offers to start a requirement from it. Send @Cade help for the short list, or see the demo and every command.

What you need

  • Node.js 20 or newer, and git
  • A Cloudflare account (the free plan is enough)
  • A Slack workspace where you can create apps
  • Optional: a Google account, for the Sheet

Your tokens stay with you

The commands that need a token or secret ask for it themselves, hidden, in your own terminal. The agent never sees one, and none is ever written to a file or a commit. It only sees whether each step worked.

What the agent sets up

Nine steps, most of them done for you

Steps marked You need a click in your browser; the agent waits for you.

  1. Get the code and run the tests
  2. Log in to CloudflareYou
  3. Name and deploy the Worker
  4. Get a Slack app configuration tokenYou
  5. Create the Slack app
  6. Install the app and store its tokenYou
  7. Set up the channels
  8. Optional: the Google Sheet
  9. Check it works

Prefer to do it yourself? The same steps, with what to expect and what to do if one fails, are in the guide the agent follows.
